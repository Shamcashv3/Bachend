# Visitor Backend

Backend بسيط (Node.js/Express) لتسجيل بيانات الزوار (IP، الجهاز، المتصفح، اللغة، الموقع الجغرافي...) لموقع مستضاف على GitHub Pages.

## الإعدادات الخاصة بك

- مستودع الموقع: https://shamcashv3.github.io
- رابط الخادم (Render): https://bachend-1-axd2.onrender.com
- توكن ipinfo.io: مُفعّل عبر متغيّر البيئة `IPINFO_TOKEN`

## 1. التشغيل محليًا (اختياري، للتجربة فقط)

```bash
npm install
cp .env.example .env
# عدّل القيم داخل .env
npm start
```

## 2. متغيرات البيئة المطلوبة على Render

في لوحة الخدمة على Render → Environment، أضف:

| Key | Value |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور قوية من اختيارك |
| `ALLOWED_ORIGIN` | `https://shamcashv3.github.io` |
| `IPINFO_TOKEN` | `0ed2148af0b92e` |

## 3. ربطه بموقع GitHub Pages

انسخ محتوى `frontend-snippet.html` كاملاً، والصقه في ملف `index.html` لموقعك قبل `</body>` مباشرة. الرابط فيه مضبوط مسبقًا على خادمك.

عند فتح الزائر للصفحة، سيظهر له طلب إذن من المتصفح نفسه للسماح بتحديد موقعه بدقة (GPS). إن وافق تُرسل إحداثياته الدقيقة، وإن رفض أو تجاهل الطلب تستمر الصفحة بإرسال باقي البيانات (IP، الجهاز، إلخ) بشكل طبيعي دون أي تعطيل.

## 4. لوحة الإدارة

افتح مباشرة من المتصفح (بدون تحميل أي ملف، لتفادي مشاكل CORS):

```
https://bachend-1-axd2.onrender.com/dashboard/
```

سجّل الدخول بكلمة `ADMIN_PASSWORD` التي وضعتها في Render. البيانات المعروضة:
- الوقت، IP، الدولة/المدينة التقريبية (عبر ipinfo.io)
- **الموقع الدقيق** (رابط "عرض على الخريطة" يفتح Google Maps على الإحداثيات بالضبط) — يظهر فقط للزوار الذين وافقوا على مشاركة موقعهم
- نوع الجهاز، النظام، المتصفح، اللغة، مصدر الزيارة

نقاط API:
- `POST /track` — تسجيل زيارة (تُستدعى تلقائيًا من كود frontend-snippet.html)
- `GET /admin/visitors` — قائمة الزوار (يتطلب هيدر `x-admin-password`)
- `GET /admin/stats` — إحصائيات (نفس الحماية)

## ملاحظات مهمة

- **الخصوصية:** أضف صفحة "سياسة الخصوصية" في موقعك توضح أنك تجمع IP، نوع الجهاز، والموقع الجغرافي عند الموافقة.
- **لا تخزّن بيانات دفع** في هذا النظام؛ هو لتحليلات الزوار فقط.
- أعد نشر الخدمة (أو انتظر إعادة النشر التلقائي بعد أي Commit) بعد إضافة متغيرات البيئة لتصبح فعّالة.
- لا ترفع ملف `.env` إلى GitHub أبدًا.
